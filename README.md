# 🚀 Personal Portfolio Website

🌐 **Live Demo:** gbhadra-portfolio.vercel.app

---

## Overview

This repository contains my personal portfolio website built using **React.js** and **Vite**. It showcases my technical skills, design experience, featured projects, and professional profile through a clean, responsive, and modern user interface.

This project was developed as part of an internship assignment and serves as the first version of my personal portfolio.

---

## Features

- Responsive portfolio design
- Interactive navigation
- About Me section
- Technical, Design & Soft Skills
- Featured Projects
- Contact Section
- Modern UI with a black and red theme
- Live deployment using Vercel
